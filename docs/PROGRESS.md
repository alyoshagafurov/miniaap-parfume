## Принятые решения

### Продуктовые

- Цены видны всем по умолчанию; переключатель в Настройках. При выключении —
  «цена по запросу», заявка собирается без сумм и минимум не проверяется.
- Каталог обязан работать и вне Telegram, обычным сайтом.
- Фотографий от клиента нет: он вносит каталог сам. Заглушка с монограммой — это
  оформленное состояние, а не сбой, и она будет видна для большинства товаров.

### Технические

- `@tma.js/*` вместо `@telegram-apps/*` — и сервер, и клиент. Набор хуков
  `sdk-react` идентичен, публикации свежее на 7 месяцев, документация старого
  пакета отдаёт 404.
- Next 16.3 / Prisma 7.10 / TypeScript 5.9. RC и новые мажоры не ставим.
- Порты 3100 / 5434 / 6381 / 9100 — только dev на этой машине.
- Олива `#4D522C` снята с логотипа. `--color-control` `#858277` для границ полей.
  «Золотая нить» — две сплошные линии, без растворения (градиенты запрещены).
- Логотип временно выводится через `mix-blend-mode: multiply` — у исходника
  непрозрачный белый фон.
- Движение: правила блока 5 вручную + `check:tokens`. Скиллы Emil в этой сессии
  недоступны; `motion-ui` не используется по решению клиента.

### Найденные дефекты, которые стоит помнить

1. Сырой `CREATE INDEX` в миграции невидим для дифера Prisma — следующая миграция
   выдала `DROP INDEX` для обоих GIN-индексов. Теперь они в `schema.prisma`,
   пустая no-op миграция служит регрессионным тестом.
2. Под `LC_CTYPE=C` pg_trgm извлекает из кириллицы ноль триграмм. Опечатки
   по-русски не работали вообще, латиница работала. Теперь `C.UTF-8`.
3. `similarity()` не проходит порог для короткого запроса к длинному стогу —
   нужен `word_similarity` / `<%`.
4. Артикул в триграммном стоге совпадал со всем каталогом. Вынесен в точную ветку.
